# Sicherheitsprobleme melden

Bitte keine Passwörter, Tokens, Modulzertifikatbindungen oder ausnutzbaren Sicherheitsdetails in öffentlichen Issues veröffentlichen.

Wenn im GitHub-Sicherheitsbereich dieses Repositorys eine private Schwachstellenmeldung angeboten wird, verwende diese Funktion. Andernfalls frage zunächst ohne technische Angriffsdetails nach einer vertraulichen Kontaktmöglichkeit.

Dieses Projekt ist eine Entwicklungsversion. Bei unerwartetem Verhalten Schreibzugriffe über den Read-only-Modus sperren. Die Integration ersetzt keine Sicherheitsfunktionen oder Wartung der Heizungsanlage.
